## Domain Wrappers

For convenience, ESI operations are also grouped into auto-generated domain-specific modules:

```python
from core.esi.public import market
from core.esi.personal import skills

orders = market.get_markets_region_id_orders(region_id=10000002, order_type="all")
char_skills = skills.get_characters_character_id_skills(character_id=12345, token=token)
```

These wrappers live in `core/esi/public/`, `core/esi/personal/`, and `core/esi/corp/`. **Do not hand-edit them** — they are regenerated by `build.py`.

## ESI Explorer

The **ESI Explorer** is a built-in tool at `/tasks/api/explorer` that lets you browse all registered ESI operations, view their parameters, schemas, and scopes, and test calls interactively.

This is useful for discovering operation IDs, understanding required parameters, and verifying that generated wrappers match your expectations.
